# HAL 9000 Piper TTS Model

This directory contains the dedicated HAL 9000 neural voice model for [Piper TTS](https://github.com/rhasspy/piper).

## Model Metadata & Provenance

- **Hugging Face Model Repository**: [campwill/HAL-9000-Piper-TTS](https://huggingface.co/campwill/HAL-9000-Piper-TTS)
- **Model Files & Direct URLs**:
  - `hal.onnx`: `https://huggingface.co/campwill/HAL-9000-Piper-TTS/resolve/main/hal.onnx`
  - `hal.onnx.json`: `https://huggingface.co/campwill/HAL-9000-Piper-TTS/resolve/main/hal.onnx.json`
- **Date Downloaded**: 2026-08-26
- **Model Architecture**: VITS-based neural voice synthesized with Piper TTS.
- **Native Audio Format**: 22,050 Hz, 16-bit signed PCM mono (`s16le`).
