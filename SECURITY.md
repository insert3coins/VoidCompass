# Security Policy

## Supported versions

Void Compass is maintained as a rolling community release.

| Version | Supported |
| --- | --- |
| Latest published release | Yes |
| Older releases and development snapshots | No |

Please confirm a suspected problem still occurs on the latest release before reporting it, unless testing would expose data or create additional risk.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Submit it privately through [GitHub Security Advisories](https://github.com/insert3coins/VoicCompass/security/advisories/new).

Include, where possible:

- The affected Void Compass version and installation type.
- A concise description of the impact and affected component.
- Reproduction steps or a minimal proof of concept.
- Whether credentials, commander data, local files, Discord webhooks, or network integrations are involved.
- Any mitigation you have already tested.

Before attaching diagnostics, redact commander names, Frontier IDs, API keys, webhook URLs, local usernames, journal paths, and unrelated gameplay data.

This is a volunteer-maintained project. The maintainer will aim to acknowledge a report within seven days and provide an initial assessment or progress update within fourteen days. Confirmed issues will be fixed and disclosed in a way that gives users a reasonable opportunity to update.
