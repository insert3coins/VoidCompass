# Elite Dangerous people artwork

This directory contains the local, offline portraits used by the Engineering
and Powerplay workspaces. It deliberately contains authentic Elite Dangerous
artwork rather than generated likenesses.

## Sources

- `powerplay/`: official, non-fanmade Frontier artwork from
  [Venefilyn/EDAssets](https://github.com/Venefilyn/EDAssets) at commit
  `5a9b2f82796fc65abace9439aea000155f1e6eb3`.
- `powerplay/jerome_archer.webp`, `powerplay/nakato_kaine.webp`, and
  `powerplay/yuri_grom.webp`: official Frontier character artwork archived by
  the Elite Dangerous Wiki, filling the current Powerplay 2.0 roster gaps in
  EDAssets.
- `engineers/`: in-game Engineer portraits from
  [EDDiscovery](https://github.com/EDDiscovery/EDDiscovery) at commit
  `758d69d4ecee70974c24f5e69c142994b565cfd9`.

The source repositories' software licences and Frontier artwork notice are
recorded in the root `THIRD_PARTY_NOTICES.md`.
