# Ship artwork catalogue

plus `Cyclops.png`, come from **Elite Cartoon Ship Vectors**, created by
[CMDR Qohen Leth](https://www.reddit.com/user/CMDR_Qohen_Leth/) from blueprints
by CMDR Arithon and the creator's own tracing. They are distributed under the
[Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International
licence](https://creativecommons.org/licenses/by-nc-sa/4.0/). The original
[2025 bundle and attribution are here](https://www.reddit.com/r/EliteDangerous/comments/1mnmolv/elite_cartoon_ship_vectors_elite_ships_colouring/).
