# VoidCompass // UPDATE LOG

## v5.3.7.8 // Navigation Instrument V3
**Release Date:** 2026-Aug-14

*   Replaced the Navigation HUD's former tapered status rail with **Navigation Instrument V3**: an open miniature flight-computer scene derived from the new bootloader. Normal flight uses sparse star drift and a ship vector; Supercruise uses speed lanes and a forward gate; FSS, DSS, Galaxy/System Map, docked, landed, surface, on-foot, fighter, vehicle, FSD and Fleet Carrier states each own visibly different geometry and motion.
*   Added layered, event-specific journal responses instead of routing most activity through the same tracer. Route set/clear/target, honks, FSS contacts, body scans, signal groups, valuable discoveries, Supercruise entry/drop/exit, FSD charge, hyperspace arrival, planet clearance, docking outcomes, touchdown/liftoff, vehicle hand-offs, fuel scooping, neutron boosts and hazards now animate in their own visual language over the sustained state.
*   Kept the reworked instrument theme-aware, reduced-motion compatible and shared by Standard and Expanded Navigation HUD layouts. The default compact HUD is eight pixels taller so the new state header clears the window chrome cleanly, while the bounded Canvas geometry remains comfortably inside the existing 30 FPS animation budget.
*   Restored active exobiology sampling from the current profile and startup journal after both clean restarts and crashes, preserving Survey Operations progress at 1/3, 2/3 or 3/3 without replaying rewards or notifications. Corrected the live reducer so consecutive `Sample` events advance one step at a time rather than skipping ahead.
*   Corrected biological totals after a restart by rebuilding per-body signal counts and completed organic analyses from the profile database before journal catch-up. Historical organic events are now replay-safe, and the active journal provides a lightweight recovery pass when a completed Analyse was not written to the older cache; live biology now keeps its three-node 1/3–3/3 sampler card until Analyse is committed, then returns cleanly to the system summary before the next organism begins.
*   Aligned the bootloader's Exploration Array with the left startup panel, giving both sides common boundaries, heading baselines and dividers while keeping the FSS scope and navigation vector comfortably inside the right-hand instrument.
*   Gave mining its own Navigation Instrument responses: completed prospector analysis now sweeps an asteroid silhouette, rich rocks resolve brighter material contacts, motherlodes reveal a fractured core signature, and refined cargo converges into a separate refinery cell animation.
