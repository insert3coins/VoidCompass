# VoidCompass // UPDATE LOG

## v5.7.3.1 // Sequence Recorder
**Release Date:** 2 NOV 3312 *(Galactic Standard Time)*

* **Record your own sequences.** Record bound keyboard and controller-button actions in Elite, including their holds and waits, from any sequence editor or a new custom command. Return to VoidCompass to stop; actions are assigned automatically using Elite’s panel state and bindings. Review or change the suggested actions, then save when ready. Panel keys add focus checks; app shortcuts pause during capture.
* **Fresher sell destinations.** Asking the Watcher where to sell now returns two distinct stations, prioritising market reports updated within the last 24 hours and then the best price. Older reports fill any remaining place with their age stated. Your Sell cargo radius and station filters still apply.
