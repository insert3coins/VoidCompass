# VoidCompass // UPDATE LOG

## v5.3.8.1 // HTML Galactic Atlas
**Release Date:** 2026-Aug-21

*   Replaced the complete Tk/Pillow Galactic Atlas renderer with a fully fledged, offline HTML/CSS/Three.js command map. The new GPU-driven atlas opens from the GALACTIC rail entry and provides smooth 3D Elite XYZ navigation, consistent galactic-north-up/east-right top-down and tilted defaults, cursor-centred zoom, gesture-aware right-drag panning, all 42 Codex regions, the original Milky Way artwork, vertical-structure control and responsive screen-space labels without retaining a legacy Canvas fallback.
*   Preserved and expanded the map intelligence rather than restarting it: up to 5,000 profile-retained systems, travel history, live game and waypoint routes, current ship, next waypoint, return path, valuable/biology/Codex/photo/recon/revisit/bookmark/sector layers, smart GPU clustering, search, inspection and commander annotations all move into the HTML atlas. Cyan breadcrumb history and a high-contrast animated amber navigation path now remain distinct over the Milky Way, with independent **Travel History**, **Nav Route** and **Return Path** controls.
*   Polished the browser command deck with live Elite XYZ coordinates, a camera-aware east/north compass, dynamic field scale, restrained centre reticle, concise mouse controls and highlighted camera presets. The Milky Way, region mesh and labels, systems, routes and annotations now share one corrected display transform, while stored raw Elite coordinates and exact region lookup remain unchanged.
*   Added a private loopback-only live bridge. Journal, route, profile, theme and reduced-motion changes stream to the open page as immutable snapshots; camera, layer, scope, depth and annotation edits return through a random per-session token and are applied on Tk's UI thread. The server binds only to `127.0.0.1`, loads no CDN resources and shuts down with the owning exploration workspace.
*   Smoothed the complete Navigation HUD motion lifecycle against real Tk stalls. Sustained states now begin at a deliberate animation seam, transitions and journal reactions share a bounded visual clock, route-arrival handoffs no longer jump ahead after a delayed frame, and the centre aperture remains stable when state-label lengths change.
*   Gave the fixed centre state label one restrained, theme-aware pulse beneath the text. Its small state-specific movement and transition glint add life without competing with the richer left/right instruments; reduced motion retains a quiet static mark.
*   Rebuilt **System Survey** as a compact Discovery Rail in both HUD layouts. It distinguishes unknown body counts, retained local evidence, active FSS work and verified completion; reports remaining bodies or completed DSS work; and adds restrained live-scanner, newly discovered body and completion-sweep responses without duplicating Survey Operations.
*   Refocused **Survey Operations** as a priority cockpit work list: confirmed biological and geological targets, valuable/notable bodies and active sampling remain visible, while routine no-signal planets stay in the full Explore & Survey inventory instead of making the overlay unnecessarily tall.
*   Added quiet navigation context from data Void Compass already receives: the current local body/station target, galactic route direction (coreward, rimward, spinward or trailing) and the next system's height above or below the galactic plane.
*   Added a profile-safe **System Time** clock that begins on `Location`, `FSDJump` or `CarrierJump`, resets with commander state and restores the real arrival time from journal timestamps after an application restart. Its once-per-second update does not redraw the full HUD.
