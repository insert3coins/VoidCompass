# Build Planner catalogue

`catalogue.json` is a normalized snapshot of the Elite Dangerous ship, module,
Engineering blueprint, experimental effect and material data maintained by the
[EDSY project](https://github.com/taleden/EDSY). The source revision and upstream
database version are recorded inside the JSON file.

EDSY is copyright © 2015-2025 taleden and is provided under the Creative
Commons Attribution-NonCommercial 4.0 International licence.

VoidCompass uses the data offline and provides an independently implemented
planner, calculation engine, interface and importer. EDSY's software is not
included. Elite Dangerous names and game data remain the property of Frontier
Developments plc.
